Published version

Checks whether the published site has moved on from the page you are reading, and says so without interrupting you. The comparison is on the build commit this page was made from, not on the version label beside it. Nothing is installed and nothing downloads in the background: reloading is what takes the new page. A page installs nothing, so four parts of the desktop updater have no equivalent here and are deliberately absent rather than faked: there is no staged download, no signature to verify, no restart, and nothing to roll back. Reloading is the whole installation step.

Reset settings

This clears every local setting on this page — theme, language, funny levels, attention preferences, scheduling, accent colour, text size, the display name you chose, the dialog emoji switch, the spoken-narration switch and its chosen voices, uploaded logo, uploaded personal vocabulary, and any published-version banner you set aside with Later — for this browser only. It cannot be undone. It deliberately does not clear the restricted-presentation switch, the name you gave it, or the value that turns it off: a reset button that unlocked it would be a way around the lock rather than a reset. It also leaves your authenticator accounts alone, for a related reason: those are credentials rather than settings, they are kept in their own storage key, and a reset that silently deleted them would be losing your data rather than resetting a preference. Remove them from the authenticator card, or clear this site’s storage in your browser, if that is what you want.

Local history

Every local setting change on this page is recorded here. Restoring an earlier revision creates a new entry — it never rewrites what came before, so a restore can itself be undone.

Export everything

Writes one file for every record set this page holds, all in the single format you choose. Nothing leaves this browser. While it runs it names the file it is writing and how many are done, so a run stopped part-way can tell you exactly which files you already have.

Authenticator accounts are not written here. They hold credentials, and this run has one format for every record set, so redacting them per row is the authenticator card’s own job: it exports the accounts with every secret left out, and offers a separate, separately confirmed export for the secrets themselves.

Add an account

Bring a secret that another service issued you. Nothing is generated here and nothing is sent anywhere: the secret is kept in this browser, and the codes are computed from it on this page.

Read it in

Or type it

This page refuses to save an account until it has actually computed a code from the secret, which catches a mistyped or truncated one at the moment you enter it rather than at your next sign-in. If you already hold this account in another authenticator, typing its current code above additionally checks that the secret is the same one; leaving it empty saves the account with that check not done, and says so.

Export authenticator secrets

This writes a file holding every authenticator secret this browser keeps, in the clear, along with the otpauth:// link each one came from. Anyone who opens that file can generate exactly the codes you can. The ordinary account export beside this one leaves every secret out; this is the deliberate exception, and it exists so you can move your accounts somewhere else rather than lose them.
