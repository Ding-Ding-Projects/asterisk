## Authenticator and local recovery surfaces

- Added mount-ready renderer surfaces for the vault-backed authenticator, independent per-element toy locks, local Support Tickets, and the server-graded unlock ladder.
- Pairing requires a current code before arming. Ordinary exports omit secret material and vault references.
- Lock recovery opens the exact application-data folder through the platform file manager and never deletes it automatically.
- Unlock-ladder success clears only the wait and does not create a session or change the ordinary sign-in attempt budget.
