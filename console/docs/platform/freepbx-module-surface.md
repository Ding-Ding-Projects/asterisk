# FreePBX module surface

The desktop FreePBX surface is documented in [the PBX module article](../pbx/freepbx-modules.md).
This article is the per-surface inventory anchor for implementation, localization, runtime, export,
history, and evidence records. The native catalog currently exposes published metadata, explicit
commercial and excluded dispositions, target capability states, and a bounded WSL or local Docker
module-manager boundary. Entity and published API family policies remain non-actionable until a
typed target route exists. Remote Docker and remote Linux are explicitly unavailable until an
approved remote transport is implemented.

Runtime state, database and web-service health, module actions, rollback, built-artifact interaction,
and capture evidence remain unverified until a target-backed verification pass is authorized.
