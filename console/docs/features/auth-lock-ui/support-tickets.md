# Support Tickets

Support Tickets are a local recovery desk, not a network service. The desktop surface uses one shared model for categories, severities, statuses, ticket numbers, the canned first response, and the fixed no-network disclosure. Ticket records contain a category, description, severity, status, local identifier, and opening time. The surface states that nothing is sent, no remote ticket exists, and nobody is reading the description.

The resolution action requests that the platform file manager open the exact application-data path supplied by the typed client. It never deletes the folder and does not offer a hidden deletion route. If the platform cannot open the file manager, the surface reports that failure instead of claiming success.
