# Native messaging ingress

The packaged host is the dedicated `Ding-PBX-Console-NativeMessagingHost.exe`, built by `build-native-host.ps1` through the supported MSVC path, with the supported MinGW fallback when MSVC is unavailable. The script records the executable SHA-256 and fails closed when no supported compiler or executable proof exists. It is submission-only. The browser manifest authenticates the allowlisted shipped extension id `dnpkplcgjmipnndmghkhljjoefjhidab`, the host repeats the exact 32-character id, and the desktop main process validates the complete handoff schema before opening the native destination picker or adding the handoff to the durable queue.

The host has no transfer command, snapshot, queue-read, credential, or file-write operation. It forwards one bounded JSON handoff over a random per-installation named pipe after proving the protected challenge, and returns only the desktop receipt. The desktop pipe server limits concurrent connections and requests current-user-only named-pipe access. `register-native-host.ps1` resolves the absolute installed host path, records the challenge and pipe configuration under a protected per-user directory, and registers the manifest for Chrome and Edge, returning a compact typed JSON receipt.

The transfer process performs a second parent reparse inspection after directory creation and before opening its temporary file. The packaged native-messaging resource is the authenticated ingress boundary; the browser extension itself is not part of this Oak Kay.
