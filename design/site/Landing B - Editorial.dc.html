Nothing reaches your exchange through an open shell.

Whether the target is the bundled WSL distribution, a Docker container, or a remote host over SSH, every action travels the same bounded control plane: an allowlist of read-only commands for observation, an allowlist of configuration resources for change. There is no free-text command execution, and no path that lets the interface construct an arbitrary shell invocation.

Every destructive or write action passes one confirmation flow that calls the underlying action and reports its real outcome — including refusals — rather than announcing success unconditionally.

ANATOMY OF A WRITE

i.Backup the file as it stands
ii.Stage the change out of band
iii.Validate before anything moves
iv.Apply
v.Read back what landed
vi.Compare — mismatch rolls back automatically

It brings its own exchange.

The installer carries a complete Ubuntu 24.04 root filesystem, built from this exact repository commit, with Asterisk and every runtime library already compiled in — verified by checking the closure of dynamic-library dependencies, not just a successful compile.

The console creates, verifies, stops, and removes its own WSL distribution — and it refuses to import over an existing one or remove one it did not create. Both refusals were exercised against a real Windows machine, not a scripted stand-in.

WHAT IS TRUE, IN BOTH DIRECTIONS

HOLDS TODAY

  • 791 of 794 tests pass — renderer 424/424, control plane 345/348, inventory 12/12, static site 10/10.
  • The shipped renderer is byte-identical to a fresh compile of the checked-in design reference; a drift test fails the build otherwise.
  • No sample or invented data anywhere: an unread surface stays empty with a stated reason, an unread cell renders as an em dash.
  • This static site makes zero runtime requests and carries no analytics.

NOT DONE YET

  • Nothing has been written to a real Asterisk exchange — every write path is proved only against a disposable test distribution.
  • 16 of 32 destinations show live data; 48 of 130 bound controls are deliberately unwired, counted per screen.
  • The desktop interface has no accessibility attributes yet.
  • ACL editing, sound prompts, TLS certificates, hardware trunks, fax, STIR/SHAKEN — open, in ROADMAP.md.

Unsigned, on purpose.

Code signing is out of scope by policy, so Windows shows an unknown-publisher warning when you run the installer. Expected — not tampering. Verify the SHA-256 against SHA256SUMS.txt on the same release for independent confirmation.
