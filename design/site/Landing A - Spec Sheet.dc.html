01 — CONTROL PLANE

No free-text commands. Ever.

Observation runs through 63 read-only CLI commands, each verified against Asterisk's own source. Change runs through 41 writable configuration resources — nothing else is reachable.

EVERY WRITE IS A TRANSACTION

If the post-read doesn't match what was written, the transaction rolls back automatically. Every destructive action goes through one confirmation flow that reports its real outcome — including refusals.

02 — RUNTIME

A PBX exists the moment you install.

BUNDLED · DEFAULT

WSL 2 Ubuntu

The installer carries a complete Ubuntu 24.04 root filesystem with Asterisk already compiled in — verified by checking the closure of dynamic-library dependencies, not just a successful compile. Created, verified, stopped, and removed entirely from the app.

LOCAL

Docker container

A local container discovered by project label, reached through the same bounded control plane as every other route.

REMOTE

SSH host

A remote Debian or Ubuntu host over SSH with scoped trust-on-first-use host-key handling. No route reaches a target through an unrestricted shell.

STATED PLAINLY — WHAT IS NOT DONE
  • —Nothing has been written to a real Asterisk exchange yet; every write path is proved only against a disposable test distribution.
  • —16 of 32 destinations are backed by live data. The rest render honestly empty screens, never sample content.
  • —48 of 130 bound controls remain deliberately unwired — each screen states its own count.
  • —The desktop interface has no accessibility attributes yet.
  • —ACL rules, sound prompts, TLS certificates, hardware trunks, fax, STIR/SHAKEN and more — see ROADMAP.md.
05 — DOWNLOAD

Unsigned, on purpose.

Every published Windows installer is deliberately unsigned — code signing is out of scope by policy — so Windows will show an unknown-publisher warning. This is expected and does not indicate tampering. Verify the SHA-256 against SHA256SUMS.txt on the same release for independent confirmation.
